# PartsPilot Documentation

Technical documentation for PartsPilot v2.0.0.

PartsPilot is a full-stack automotive inventory management and analytics platform built with React, TypeScript, FastAPI, PostgreSQL, Docker, and Power BI.

## Current Release

**PartsPilot v2.0.0**

The main product development cycle is complete.

The release includes:

- JWT authentication
- Inventory management
- Supplier management
- Operational dashboard
- Reports and CSV export
- Power BI analytics
- PostgreSQL persistence
- Responsive desktop and mobile interfaces
- Docker-based local development
- GitHub Actions CI

PartsPilot is now maintained rather than actively expanded with major new product features.
